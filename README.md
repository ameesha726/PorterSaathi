## Porter Saathi 🤖

**Porter Saathi** is an AI **voice-first assistant** 🎤 designed to bridge this gap and empower users.
Many driver-partners 🚚 face challenges due to limited literacy, making everyday tasks like reading instructions or understanding updates difficult.

## Features ✨

  - **Voice-first assistant:** Interact using voice commands. 🗣️
  - **Real-time answers:** Get answers in **English** and **Hindi**. 🌐
  - **Text to Voice:** Converts text-based information into conversational voice interactions. 📄➡️💬
  - **Modern UI:** A responsive user interface for seamless accessibility. 📱💻

## Tech Stack 🛠️

  - **Frontend:** React (Vite) ⚛️
  - **AI / NLP:** Google Gemini API 🧠
  - **Voice Interaction:** Text-to-Speech (TTS) 🔊
  - **Deployment / Hosting:** Vercel 🚀

## Usage 💻

1.  Clone the repository.
2.  Install dependencies:
    ```
    npm install
    ```
3.  Start the development server:
    ```
    npm run dev
    ```

## Deployment 🌐

The project is deployed on Vercel.
Check out the live app here: [https://porter-saathi-etwh.vercel.app/](https://porter-saathi-etwh.vercel.app/) 🔗
